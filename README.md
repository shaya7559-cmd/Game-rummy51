# רמי 51 — ניהול ניקוד

אפליקציית ווב לטלפון שמנהלת משחק רמי 51: מי מחלק, תורי גלוק ופריש, ניקוד, טורנירים עם טבלה לפי הניקוד הכללי, היסטוריה ודוחות.
היא בנויה מ-HTML, CSS ו-JavaScript רגילים, בלי שלב בנייה, ומתארחת ב-GitHub Pages.

## הכללים שהאפליקציה מנהלת
- **מחלק:** השחקן שנבחר מחלק ראשון, ובכל תור עוברים לשחקן הבא לפי סדר הישיבה.
- **גלוק:** כל תור רביעי (4, 8, 12…). פריש הופך את התור הנוכחי לגלוק, ואם הוא כבר גלוק, את התור הפנוי הבא. אם אין תור פנוי, האפליקציה מציעה להוסיף תור גלוק. אפשר גם להפוך תור לגלוק ידנית.
- **פריש:** אותו מחלק מחלק שוב ואף אחד לא מקבל נקודות.
- **ניקוד:** המנצח מקבל ‎-30, מי שלא הוריד סדרה מקבל 100, וכל השאר מקבלים את סכום הקלפים. האנט ×2, גלוק ×2, ושניהם יחד ×4. ההכפלה חלה על הכול.
- **משחק:** ‏12 תורים. אפשר להוסיף תורים או לסיים מוקדם. המנצח הוא מי שצבר הכי מעט נקודות, ובתיקו בוחרים מנצח.
- **טורניר:** קבוצת משתתפים קבועה שמשחקת כמה משחקים. כולם משחקים בכל משחק; הרכב אחר = טורניר חדש. כשפותחים טורניר עם הרכב שכבר יש לו טורניר פעיל, האפליקציה מציעה להמשיך אותו.
- **מסך הטורניר:** שורה לכל משתתף: מקום, שם (ו-🏆 עם מספר הניצחונות), הניקוד במשחק הנוכחי והניקוד הכללי. הטבלה ממוינת לפי הניקוד הכללי של המשחקים שהסתיימו: **הכי מעט נקודות במקום הראשון**, ובשוויון מי שניצח ביותר משחקים. המקומות משתנים רק בסוף משחק, ו-▲/▼ מראים מי עלה או ירד במשחק האחרון. טבלת התורים של המשחק סגורה מתחת לשורות ("פירוט התורים במשחק").
- **תיקון נקודות:** לחיצה על משתתף מציגה את הנקודות שלו בכל תור; לחיצה על תור פותחת אותו לתיקון. גם משחק שהסתיים אפשר לתקן (מהיסטוריה או מרשימת המשחקים בטורניר). המכפילים מחושבים מחדש, ואם המנצח במשחק משתנה, האפליקציה מעדכנת אותו (ובתיקו שואלת).

## העלאה ל-GitHub Pages
1. ב-<https://github.com/new> יוצרים מאגר **ציבורי** בשם `rummy51`, בלי README.
2. מתוך התיקייה הזו:
   ```bash
   git init
   git add .
   git commit -m "Rummy 51 scorekeeper"
   git branch -M main
   git remote add origin https://github.com/<USER>/rummy51.git
   git push -u origin main
   ```
3. במאגר: ‏**Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save**.
4. אחרי כדקה האפליקציה זמינה בכתובת `https://<USER>.github.io/rummy51/`. בטלפון פותחים את הכתובת ובוחרים "הוסף למסך הבית".

## שמירת המשחקים בגיט
המשחקים נשמרים במאגר **נפרד ופרטי**, ולא במאגר הציבורי של האפליקציה, כדי שהתוצאות לא יהיו גלויות לכולם.
1. יוצרים מאגר פרטי, למשל `rummy51-data`, עם README.
2. יוצרים Fine-grained token שיש לו גישה **רק** למאגר הזה, עם ההרשאה **Contents: Read and write**.
3. באפליקציה: **גיט וגיבוי** ← מזינים `<USER>/rummy51-data` ואת הטוקן ← **חבר ובדוק**.

מבנה הקבצים במאגר הנתונים:
```
data/tournaments/<id>.json   קובץ לכל טורניר: המשתתפים, כל המשחקים עם כל התורים, והמשחק שבאמצע
```
בכל קובץ יש גם `summary` קריא: הטבלה (מקום, נקודות, ניצחונות), הניקוד של כל משתתף בכל משחק, והמשחק הפתוח. ממנו אפשר להפיק כל דוח. האפליקציה לא קוראת אותו, היא מחשבת הכול מחדש מהנתונים.

הקבצים של הגרסה הקודמת (`data/games/`, `data/current.json`, `data/tournaments.json`) נקראים פעם אחת, עוברים לטורנירים, ונשארים במאגר בלי שינוי. גם בטלפון, הנתונים הישנים (`rummy51.v1`) עוברים פעם אחת למבנה החדש (`rummy51.v2`) והעותק הישן נשאר.
הטוקן נשמר רק בטלפון (`localStorage`) ואף פעם לא נכנס לקוד. בטלפון חדש מתחברים עם אותו מאגר, וכל ההיסטוריה נטענת.
